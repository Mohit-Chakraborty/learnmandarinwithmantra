# Stroke data

These files are copied unchanged from [hanzi-writer-data](https://github.com/chanind/hanzi-writer-data) version 2.0.1, which derives them from the [Make Me a Hanzi](https://github.com/skishore/makemeahanzi) project and the Arphic PL fonts.

They are distributed under the Arphic Public License; the full text is in `ARPHICPL.TXT` in this folder.

Only the characters used on this site are included. Each file is named after its character, for example `人.json`.
